# Farming Course — Membuat Game Farming ala Stardew Valley dengan Unity 2D

> Course gratis (Bahasa Indonesia) untuk membuat farming game ala *Stardew Valley* dengan Unity 2D top-down — dari nol sampai bisa dimainkan.

**📖 Baca course di:** **<https://ridz15.github.io/FarmingCourse/>**

Versi rendered (MkDocs Material) ada di link di atas — search, dark mode, navigasi cepat. Kalau lebih suka baca markdown mentah di GitHub, semua chapter ada di folder [`docs/`](docs/).

---

## Apa yang Dibangun?

Prototype farming game 2D top-down lengkap: karakter, tilemap dunia, hoe/watering can/seed, sistem tumbuh-panen, inventory, day-night, season, NPC & shop, save/load, audio, dan build executable. Total 13 chapter, ±20 jam belajar aktif.

Lihat outline lengkap di [docs/index.md](docs/index.md) atau kunjungi [situs course](https://ridz15.github.io/FarmingCourse/).
