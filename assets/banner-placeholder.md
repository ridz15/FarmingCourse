# Banner & Asset Placeholders

This folder holds documentation about assets used by the course.

The `README.md` references `assets/banner-placeholder.md` instead of an actual
image so the repo stays small. Replace this with a real banner if you build one.

## Suggested banners

- 1280×400 PNG, top-down screenshot of the finished farm scene.
- Pixel art logo "FarmingCourse" overlay.
